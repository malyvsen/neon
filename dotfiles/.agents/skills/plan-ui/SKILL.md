# Plan UI

1. Copy [example.html](example.html) to the workspace's artifact directory and edit it to produce a mockup of the proposed UI, paying attention to mimic the app's styling. Open it in a browser and iterate with the user.
2. Once the user is happy with the mockup, write a plan for implementing the changes in code, following `/write-plan`. Refer to the HTML mockup by its file path.
